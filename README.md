# 📅 Telegram Bot — Запис клієнтів до майстра

Повністю асинхронний Telegram-бот на **aiogram 3.x** + **SQLite** для запису клієнтів до майстра (ресниці, нігті, барбер тощо).

---

## 🚀 Швидкий старт

### 1. Встановити залежності

```bash
pip install -r requirements.txt
```

### 2. Налаштувати `.env`

```bash
cp .env.example .env
```

Відкрийте `.env` і вкажіть:

```env
BOT_TOKEN=ваш_токен_від_@BotFather
ADMIN_ID=ваш_telegram_id        # дізнатись у @userinfobot
MASTER_NAME=Марія — Майстер по ресницях
MAX_APPOINTMENTS_PER_DAY=10
REMINDER_HOURS_BEFORE=24
```

### 3. Запустити бота

```bash
python bot.py
```

### 4. Завантажити демо-розклад (перший запуск)

Напишіть боту команду: `/seed`  
Буде створено розклад Пн–Пт на 14 днів вперед.

## 👤 Функціонал клієнта

| Дія | Опис |
|-----|------|
| `/start` | Вітання і головне меню |
| 📅 Записатись | 6-крокова FSM-форма запису |
| 📋 Мої записи | Перегляд активних записів |
| ❌ Скасувати запис | Скасування через кнопку |
| ℹ️ Про майстра | Послуги і тривалість |
| 📞 Контакти | Час роботи і контакти |

### Процес запису (6 кроків):
1. Вибір послуги
2. Вибір дати (тільки дати з вільними слотами)
3. Вибір часу (тільки доступні слоти)
4. Введення імені (або кнопка «💾 Використати збережене»)
5. Введення телефону (або «💾 Збережений» / «📲 Поділитись номером»)
6. Підтвердження → клієнт і майстер отримують сповіщення

На **кожному кроці** є кнопка «◀️ Назад».

## 🧑‍💼 Функціонал адміністратора

Авторизація: автоматична, за `ADMIN_ID` з `.env`.

| Команда/кнопка | Дія |
|----------------|-----|
| `/admin` | Відкрити панель |
| `/seed` | Завантажити демо-розклад (14 днів) |
| 📋 Всі записи | Переглянути майбутні записи |
| 📅 Розклад | Переглянути/закрити/відкрити слоти на дату |
| ➕ Додати слоти | Вручну (формат: `15.01.2025 09:00`) |
| 🗓 Згенерувати тиждень | Авто-розклад Пн–Пт 09:00–17:00 |
| 👤 Режим клієнта | Переключитись у вигляд клієнта |

## 🗄 База даних (SQLite)

**users** — `id, telegram_id, name, phone, created_at`

**appointments** — `id, user_id, date, time, service, status, created_at`  
Статуси: `confirmed | cancelled | completed`

**schedule** — `id, date, time, is_available`

---

## 🔔 Сповіщення

- **Майстер** отримує: новий запис, скасування клієнтом
- **Клієнт** отримує: підтвердження запису, нагадування за N годин, повідомлення якщо майстер скасував
- **Нагадування** — планувальник щогодини перевіряє записи

    "Барбер (стрижка)": 45,
